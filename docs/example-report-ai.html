Invisible Unicode Tag Text In LLM Input

First seen
2026-10-21 09:00:06Z
Events
1 event(s)
  • AML.T0051 LLM Prompt Injection
  • AML.T0068 LLM Prompt Obfuscation

What the rule looks for

A prompt, a retrieved document or a tool result contains text written in Unicode tag characters (U+E0020 to U+E007E). They mirror printable ASCII but are invisible on screen, while language models read them, so they carry instructions the user never sees ("ASCII smuggling"). Their only legitimate use, the flags of England, Scotland and Wales, is left out by the parser. The decoded text is shown in the alert.

First seen
2026-10-21 17:00:01Z

  • AML.T0110 AI Agent Tool Poisoning

What the rule looks for

An MCP server listed a tool (in its answer to tools/list) whose description, or the description of one of its parameters, carries instructions meant for the model rather than documentation of the tool. The rule looks for the wording of prompt injections ("ignore previous instructions"), text addressed to AI assistants, the <IMPORTANT> blocks of tool poisoning attacks, requests to hide something from the user ("do not mention that you read the file"), text hidden in invisible Unicode tag characters, a sentence that changes how another tool behaves ("when this tool is available, the send_email tool must..."), and instructions to read credential files (SSH keys, cloud credentials, mcp.json) or the results of other tools and pass them along in an argument. The model reads the description of every tool it is offered before it calls any of them, so the server steers the agent even if the tool is never called. Check which server offered the tool, whether its description changed since the server was approved, and the tool calls that followed in the session.
